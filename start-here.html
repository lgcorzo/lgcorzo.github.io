Dark Gravity: Complete Architectural & Empirical Orientation in 5 Minutes

Dark Gravity is an experimental Continuous Agentic / Continuous Deployment (CA/CD) software factory built in Rust Edition 2024 and Kubernetes. Do not evaluate any individual @lgcorzo repository in isolation — inspect the integrated topology across the seven sections below.

Open Canonical /start-here/ AI Agents Portal Auditor Pack Knowledge Graph JSON

1. Executive Summary

Dark Gravity converts labeled GitHub issues into verified Pull Requests through a 5-phase durable mission pipeline (rustant-plan, zeroclaw-execute, zeroclaw-validate, rustant-review, factory-deliver) after Kafka mission-input ingestion. Autonomous merges into main are strictly forbidden by Vertex 4 HITL governance. Compliance wording: all controls are architectural readiness measures; No third-party certification (EU AI Act, SOC 2 or other) is claimed.

2. Architecture Overview

Five Rust Edition 2024 Onion crates (rust_CACD_autonomous_factory v0.3.4), five Hatchet steps, Ed25519 W3C-VC signing, 300 s Vault JIT credentials (54.2 ns zeroize), OpenZiti mTLS, and gVisor (runsc) sandboxes (FR-008/CTRL-02 kept TESTED while AUD-010 is open). See Architecture and Auditor Architecture Pack.

3. Repository Map & Fork Policy

Total portfolio: 64 public repositories (22 original + 42 maintained open-source forks under MAINTAINED_FORK_PROFILE), reconciled with 69 historical baseline and 72 Spec 004 inventory (private repos redacted under DOC-011 as Internal GitOps Control Plane and Internal Incident Remediation Service). lgcorzo/kes is permanently FROZEN_READONLY. See REPOSITORIES.md and Fork policy.

4. Research Vision (RQ1–RQ4)

Four formal research hypotheses track MTTR reduction (RQ1), cryptographic NHI governance (RQ2), GitOps & sandbox security boundaries (RQ3), and AST/GraphRAG workflow efficiency (RQ4). See RESEARCH.md.

5. Experiments Catalog (EXP-2026-001..014)

Covers EXP-2026-001 through EXP-2026-014 including Mission #476 (2m57s DAG, 87/87 R2R Hatchet tasks) and Swarm Mode Mission #478 (3 parallel lanes, 3x r2r-reader replicas). See EXPERIMENTS.md and Lab notebook.

6. Platform Metrics & Epistemic Evidence

Thirteen KPIs across Development, Quality, Security, and Agents live in data/metrics.json and metrics.html; unmeasured fleet baselines remain labeled UNMEASURED (baseline_pending).

7. AI Agent Quick-Entry, MCP & Knowledge Graph

Agents can query /ai-agents/, DARK_GRAVITY_MANIFEST.md, knowledge_graph.json, knowledge_graph.graphml, knowledge_graph.rdf, or run read-only Rust dark-gravity-mcp.
