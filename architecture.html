Architecture: how Dark Gravity is built and where it runs

This page answers six questions, in order. Each section heading is the question it answers.

In one minute

  • The code is five Rust crates. The inner crate does no I/O.
  • A mission is five Hatchet steps. Untrusted code runs only in a gVisor sandbox.
  • ADR-008 adds a Kubernetes object, AgentWorkspace, and hard sandbox limits.
  • Tags show how much is proven: Designed, Implemented, Deployed, Verified.

How is the code organised?

The workspace has five crates in Rust edition 2024. They are layered like an onion: inner crates know nothing about outer ones. That keeps business rules free of network and disk code.

CrateLayerWhat it does
factory-coreDomainMission and task types, errors, and security rules. No I/O.
factory-applicationApplicationThe agents and the Hatchet workflows that use them.
factory-infrastructureAdaptersClients for Kafka, Vault, OpenZiti, R2R, S3 and Git hosts.
factory-mcp-serverInterfaceAn MCP server on port 8100. It offers tools, including the one that launches sandbox jobs.
factory-cliEntry pointRuns the Hatchet worker, the Git poller and the workspace operator.

Status: Implemented Source: Cargo.toml.

The agents are Rustant (plans and reviews), ZeroClaw (writes and tests code), plus AuditorAgent, FinOpsAgent, QAObserver and DocAgent.

How does a mission flow?

A poller reads labelled issues from GitHub or GitLab, signs the request, and publishes it to the Kafka topic mission-input. The worker starts a Hatchet workflow with five tasks. Hatchet retries a task if its worker dies.

  1. rustant-planLooks up context in R2R and writes the plan and task list with Spec Kit.
  2. zeroclaw-executeApplies the tasks to the code through the Spec Kit bridge, in a sandbox job.
  3. zeroclaw-validateRuns tests and linters in the sandbox.
  4. rustant-reviewAn AI judge scores the diff for security. A score below 8.0 out of 10 rejects it.
  5. factory-deliverOpens a pull request that links the issue. A human reviews and merges.

Status: Deployed Task names: autonomous_mission.rs. A full run was seen in the Hatchet dashboard on v0.2.8; no evidence file records it yet.

Kafka naming: the poller and worker use mission-input. The name mission-ingestion appears only in a test binary, an inspection tool and ADR-008. The owner should confirm which is intended.

What is the ADR-008 standard?

ADR-008 describes a Kubernetes-native way to manage agent workspaces. It adds a custom resource, AgentWorkspace, which says which repository and branch an agent may work on and how much memory and CPU it gets. An operator written in Rust (kube-rs) reconciles it.

What the object holds

Repository URL and target branch (both immutable), a mission reference, a constitution file path, and resource limits. Its phase is one of Pending, Initializing, Running, Paused, Completed or Failed.

The sandbox bound

In the development namespace every container must declare requests and limits, with memory at most 30Mi and CPU at most 250m. Ephemeral containers are refused. The bound covers the workload, not gVisor’s own overhead, which the ADR says is still to be measured.

What are the security boundaries?

BoundaryHow it worksStatus
SandboxGenerated code runs under gVisor (runtime class gvisor, handler runsc). Firecracker was considered and not chosen, because gVisor starts faster and fits Kubernetes.Deployed
Resource limits30Mi and 250m per container, checked when the job is created.Deployed
IdentityMissions are signed with Ed25519 keys as W3C verifiable credentials.Implemented
SecretsVault tokens that last five minutes, wiped from memory on drop.Implemented
NetworkOpenZiti overlay. The controller and router run; the claim of zero inbound ports is not verified here.Deployed
SpendHalts missions at 90% of a daily budget (default $50, so $45) and flags a rise above $1 per minute.Implemented
Human approvalThe pipeline only opens a pull or merge request. It has no merge step, so a person merges.Implemented

Read the threat model for the attacks considered. It mentions both gVisor and Firecracker, so it overstates the choice.
