Dark Gravity Autonomous Software Factory

Dark Gravity is a Rust-based autonomous engineering platform for zero-trust and security-critical software factories, coordinating multi-agent workflows under formal human-in-the-loop governance. Today it runs as a 5-crate Rust workspace (v0.2.8) integrated with Kubernetes CRDs, Hatchet durable DAGs, and gVisor sandboxing; core DAG phases and admission controls are deployed and verified, while multi-node chaos testing remains designed.

Core technical guarantees

Micro-sandboxing (gVisor)

All untrusted code generation and compilation runs inside user-space kernel sandboxes (RuntimeClass=gvisor). In sandbox namespaces, admission policies enforce memory clamping to 30 MiB and CPU limits to 250m.

Human-in-the-loop requirement

Agents produce clean PRs and link originating issues, but automated direct merges to default branches are blocked by policy. A human engineer must always review, verify CI evidence, and merge manually.
