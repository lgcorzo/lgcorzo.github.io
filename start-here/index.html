1. Executive Summary

Dark Gravity converts labeled GitHub issues into verified Pull Requests through a 5-phase durable mission pipeline (rustant-plan, zeroclaw-execute, zeroclaw-validate, rustant-review, factory-deliver) triggered from Kafka mission-input ingestion. Autonomous merges into main are prohibited by Vertex 4 Human-in-the-Loop (HITL) governance.

Compliance wording: all EU AI Act and SOC 2 controls represent architectural readiness measures. No third-party certification (EU AI Act, SOC 2 or other) is claimed.

2. Architecture Overview

Core Rust Orchestrator

rust_CACD_autonomous_factory (v0.3.4) implements 5 Rust Edition 2024 Onion crates (factory-core, factory-application, factory-infrastructure, factory-mcp-server, factory-cli), running five Hatchet steps backed by CloudNativePG state checkpoints.

Deep architecture walkthrough →

Zero-Trust Runtime & NHI

Execution sandboxes run via gVisor (runsc) (30Mi/250m micro-sandbox or 512Mi/500m compilation) with Ed25519 W3C-VC signing and 300 s Vault JIT credentials (54.2 ns zeroize). FR-008/CTRL-02 remains labeled TESTED while AUD-010 is open.
