The 4 Pillars of Sovereign Ecosystem Autonomy

As documented in the official @lgcorzo/docs architectural charter, the Dark Gravity ecosystem maintains absolute decoupling from external upstream entities (including upstream MinIO and third-party tooling). All software artifacts running in production are compiled, scanned, packaged, and deployed solely through controlled sovereign pipelines.

PILLAR 1

Git Remote Topology

Zero active upstream remotes. All default branches (main/master) push exclusively to github.com/lgcorzo/* under isolated access controls and mandatory branch protection.

PILLAR 2

Hermetic Container Registry

Upstream image registries (quay.io, docker.io) are decommissioned. All images are compiled hermetically via GitHub Actions and published directly to ghcr.io/lgcorzo/*.

PILLAR 3

Zero-:latest Policy

All production manifests, Helm charts, and Kustomize overlays bind to immutable semantic tags (v*.*.*-lgcorzo.*), preventing silent downstream poisoning or non-reproducible deployments.

PILLAR 4

No Upstream Rebase

Upstream commits are treated as third-party reference sources, never as authoritative base branches. No destructive automated rebases occur; all updates pass through human-in-the-loop validation.
